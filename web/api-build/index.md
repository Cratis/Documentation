# Cratis API reference

The .NET API reference for the Cratis libraries, generated from their XML documentation comments and organized by namespace. It covers seven assemblies:

- **Chronicle**: the .NET client (`Cratis.Chronicle`), its ASP.NET Core integration (`Cratis.Chronicle.AspNetCore`), and the testing helpers (`Cratis.Chronicle.Testing`).
- **Arc**: the ASP.NET Core framework (`Cratis.Arc`), the core command and query pipelines (`Cratis.Arc.Core`), and MongoDB read-model persistence (`Cratis.Arc.MongoDB`).
- **Fundamentals**: the shared building blocks such as concepts, serialization and type discovery (`Cratis.Fundamentals`).

A namespace or extension class that several assemblies contribute to has one page, which lists those assemblies. Older per-library type and member URLs redirect to these pages; with JavaScript enabled, the redirect keeps the member fragment.

The TypeScript reference for the `@cratis/arc` packages and `@cratis/fundamentals` is listed on the [API reference overview](/api-reference/). Guides, concepts and tutorials are on the [main documentation site](/).
