# Cratis API reference

The generated .NET API reference for the Cratis client libraries, organized by namespace.
The reference includes:

- **Chronicle** — the event store clients: the DotNET client, the AspNetCore integration, and the Testing helpers.
- **Arc** — the hosting integration, **Arc.Core** command and query APIs, and MongoDB integration.
- **Fundamentals** — the shared building blocks (concepts, types, serialization).

Shared namespaces and extension classes have one canonical page listing their contributing
assemblies. Existing per-library type and member URLs redirect to these pages, preserving
member fragments.

For the TypeScript / JavaScript API (`@cratis/*` packages) and the narrative documentation,
return to the [main documentation site](/).
